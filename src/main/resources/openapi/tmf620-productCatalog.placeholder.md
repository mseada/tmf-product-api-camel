# TMF620 – Product Catalog Management API – OpenAPI Spec

Place the official TMF620 OpenAPI YAML/JSON specification here.

Source: https://github.com/mseada/Open_Api_And_Data_Model
Path in forked repo: apis/TMF620_Product_Catalog/

The `camel-openapi-java-starter` auto-generates a live spec at runtime from the
REST DSL definitions in `ProductCatalogRoute.java`.
You can also serve the official static spec from this directory by wiring a
Spring MVC resource handler.
