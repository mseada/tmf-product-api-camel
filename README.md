# tmf-product-api-camel

> **TM Forum Product APIs implemented with Apache Camel on Spring Boot**
>
> Implements [TMF620 – Product Catalog Management](https://www.tmforum.org/resources/standard/tmf620-product-catalog-management-api-rest-specification-r19-0-0/)
> and [TMF622 – Product Ordering Management](https://www.tmforum.org/resources/standard/tmf622-product-ordering-management-api-rest-specification-r19-0-0/)
> using Apache Camel's REST DSL running on Spring Boot 3 / Java 21.

---

## Tech Stack

| Layer | Technology |
|---|---|
| Language | Java 21 |
| Framework | Spring Boot 3.3.x |
| Integration | Apache Camel 4.8.x |
| REST transport | Camel Servlet (via Spring MVC) |
| JSON | Jackson via `camel-jackson` |
| API docs | Auto-generated OpenAPI via `camel-openapi-java` |
| Build | Maven |

---

## Project Structure

```
src/main/java/com/mseada/tmf/
├── TmfProductApiApplication.java          # Spring Boot entry point
├── routes/
│   ├── RestConfigurationRoute.java        # Global REST DSL + OpenAPI config
│   ├── ProductCatalogRoute.java           # TMF620 REST endpoints
│   └── ProductOrderingRoute.java          # TMF622 REST endpoints
├── model/
│   ├── Catalog.java                       # TMF620 Catalog resource
│   ├── CategoryRef.java                   # Category reference
│   ├── ProductOrder.java                  # TMF622 ProductOrder resource
│   ├── ProductOrderItem.java              # Order line item
│   ├── ProductOfferingRef.java            # ProductOffering reference
│   └── RelatedParty.java                  # Common party reference
└── processor/
    ├── CatalogQueryProcessor.java         # Builds TMF620 list response
    ├── CatalogService.java                # In-memory catalog store
    ├── ProductOrderProcessor.java         # Enriches incoming orders
    └── ProductOrderService.java           # In-memory order store

src/main/resources/
├── application.yml                        # Spring Boot + Camel config
└── openapi/                               # Drop official TMF spec YAMLs here
    ├── tmf620-productCatalog.placeholder.md
    └── tmf622-productOrdering.placeholder.md
```

## API Endpoints

All endpoints are served under the Camel servlet context path `/camel/`.

### TMF620 – Product Catalog Management

| Method | Path | Description |
|--------|------|-------------|
| `GET`  | `/camel/productCatalogManagement/v4/catalog` | List all catalogs |
| `GET`  | `/camel/productCatalogManagement/v4/catalog/{id}` | Get catalog by ID |
| `POST` | `/camel/productCatalogManagement/v4/catalog` | Create a catalog |

### TMF622 – Product Ordering Management

| Method  | Path | Description |
|---------|------|-------------|
| `GET`   | `/camel/productOrderingManagement/v4/productOrder` | List all orders |
| `GET`   | `/camel/productOrderingManagement/v4/productOrder/{id}` | Get order by ID |
| `POST`  | `/camel/productOrderingManagement/v4/productOrder` | Submit a new order |
| `PATCH` | `/camel/productOrderingManagement/v4/productOrder/{id}` | Partially update an order |

### OpenAPI / Swagger

Live API documentation is auto-generated by `camel-openapi-java`:

```
GET http://localhost:8080/camel/api-doc
```

## Getting Started

### Prerequisites

- Java 21+
- Maven 3.9+

### Run

```bash
mvn spring-boot:run
```

The server starts on port **8080**.

### Quick smoke test

```bash
# List catalogs
curl http://localhost:8080/camel/productCatalogManagement/v4/catalog

# Submit a product order
curl -X POST http://localhost:8080/camel/productOrderingManagement/v4/productOrder \
  -H "Content-Type: application/json" \
  -d '{
    "description": "New broadband order",
    "requestedCompletionDate": "2026-06-01T00:00:00Z",
    "productOrderItem": [
      {
        "id": "1",
        "quantity": 1,
        "action": "add",
        "productOffering": { "id": "PO-001", "name": "Home Fibre 500Mbps" }
      }
    ]
  }'
```

### Build & test

```bash
mvn clean verify
```

## OpenAPI Specs

The official TM Forum API specs live in the forked repository:

`src/main/resources/openapi/` and wire a Spring MVC resource handler.
